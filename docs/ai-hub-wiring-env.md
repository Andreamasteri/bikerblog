# Inactive AI-Hub environment contract

The following names are placeholders only; secret values must be supplied by
the deployment secret manager and must never be committed:

- AI_HUB_WIRING_ENABLED=false
- AI_HUB_CONTROL_URL=
- AI_HUB_BEARER_TOKEN=

The route exposes the static capability registry, including Crea colonna
sonora -> Nadir, but the job adapter refuses traffic while the flag is false.
